One joke about Monday mornings, 200 characters at most, judged on laughs. A single TypeScript program (Node 22, standard library only) that writes the joke to `/output/entry.txt`. The joke treats Monday morning as the clingy partner who will not leave: "we need to talk" meets "We talk every week" — and it sits down for five days.

## Run it

```sh
node main.ts
```
